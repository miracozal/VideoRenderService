# Reels music files

The renderer selects a market-specific MP3 when the corresponding file exists.
Only audio that is licensed for use in published social-media content should be
placed in this directory. The Migros, Trendyol, Hepsiburada and Gratis tracks in
this repository are original project cues generated by
`scripts/generate_market_jingles.py`; they are not official brand jingles and do
not reproduce official advertising melodies.

Expected file names:

- `a101_soundtrack.mp3`
- `bim_soundtrack.mp3`
- `sok_soundtrack.mp3`
- `migros_soundtrack.mp3`
- `trendyol_soundtrack.mp3`
- `hepsiburada_soundtrack.mp3`
- `gratis_soundtrack.mp3`

`kontraa_water_afro_pop_music.mp3` is the generic fallback. If a market-specific
file is missing, the renderer uses this fallback instead of another market's
jingle.
